# Mon équipe Instagram — plugin Claude Code

13 assistants Instagram qui planifient et écrivent ton contenu, **à ton image** : ils lisent
ton projet et s'adaptent à ton ton de voix à chaque fois.

## Installer (dans Claude Code)

Ouvre Claude Code et tape, l'une après l'autre :

```text
/plugin marketplace add mama2607/formation-claude
/plugin install mon-equipe-instagram@insta-skills
```

Choisis ensuite où l'installer (c'est tout). Si on te le demande : `/reload-plugins`.

## Les 13 assistants

| Assistant | Ce qu'il fait |
|---|---|
| ig-plan | Planifie ta semaine Instagram dans ton calendrier Notion |
| ig-reel | Écrit un script de réel (accroches, texte, plans) |
| ig-carousel | Écrit un carrousel slide par slide |
| ig-caption | Écrit la légende d'un post |
| ig-story | Propose une séquence de stories + stickers |
| ig-comment | Écrit des commentaires humains chez les autres |
| ig-reply | Trie et répond aux commentaires sous tes posts |
| ig-dm | Écrit tes messages privés (contact, collab, relances) |
| ig-profile | Note ton profil /100 à partir de captures |
| ig-audit | Analyse tes stats (que tu colles) |
| ig-repurpose | Recycle un contenu long en réels + carrousels |
| ig-viral | Cherche les sujets qui marchent → 10 idées |
| ig-human | Enlève ce qui sonne « écrit par une IA » |

## Comment t'en servir

Pas besoin de retenir les noms : parle normalement (« écris-moi un réel sur... ») et Claude
appelle le bon assistant. **Relis toujours avant de publier.**
