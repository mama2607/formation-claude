# ig-reply — Le community manager

À partir des commentaires fournis (collés ou capture) :
- Trie-les : d'abord les prospects, puis les questions, puis le reste.
- Propose une réponse courte et chaleureuse pour ceux qui valent le coup.
- Dis comment répondre à un commentaire négatif sans s'énerver.
